Technical Q&A

Commonly asked data engineering interview concepts.

Job Bookmarks maintain state information and prevent the reprocessing of old data. This ensures that only new files added to S3 since the last run are processed, saving significantly on costs and time.

Lambda is best for short-lived, event-driven tasks (under 15 mins) like file validation or triggering jobs. Glue is meant for heavy data processing, handling terabytes of data with distributed Spark clusters.

Airflow provides complex dependency management, automated retries, and a rich UI to monitor DAGs. It allows us to orchestrate tasks across different platforms (AWS, GCP, On-prem) seamlessly.
