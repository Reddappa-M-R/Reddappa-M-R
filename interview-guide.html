Data Engineering Cheatsheet

Quick Reference for 2026 Technical Interviews

Focus on System Design and Data Modeling—these are the top-weighted topics in 2026.

SQL Essentials

  • Window Functions: DENSE_RANK vs ROW_NUMBER.
  • Handling Duplicates: Using CTEs with QUALIFY.
  • Performance: Avoiding SELECT * and using Partition Pruning.
  • Joins: Differences between Hash Join, Merge Join, and Nested Loops.

Python & Coding

  • Data Structures: Time complexity of List vs Set lookups.
  • Memory Management: Using yield for large file streaming.
  • Testing: Unit testing ETL logic with pytest.
  • Concurrency: Multi-threading vs Multi-processing for I/O tasks.

Apache Spark

  • Lazy Evaluation: Understanding Directed Acyclic Graphs (DAGs).
  • Transformations: Narrow vs Wide (Shuffling) operations.
  • Optimization: Persisting vs Caching and Broadcast Variables.
  • Data Drift: Identifying and handling schema evolution.

System Design

  • Batch vs Stream: Lambda vs Kappa Architectures.
  • Data Modeling: Star Schema vs Snowflake Schema.
  • SLA/SLO: Designing for high availability and fault tolerance.
  • Backfill Strategy: How to re-run 1 year of data efficiently.

Behavioral Strategy

Use the STAR Method (Situation, Task, Action, Result) for all questions. As a Data Engineer, always emphasize the Impact: "Reduced cost by X%" or "Saved Y hours of manual work."
